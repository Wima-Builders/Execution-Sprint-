WIMA BUILDERS — GITHUB PACKAGE v1.0
======================================

UPLOAD THESE 3 FILES TO THE ROOT OF YOUR GITHUB PAGES REPOSITORY:

1. index.html
   Main Wima Strategy Hub / landing page.

2. operating-system.html
   CEO Operating System / execution centre.

3. lecture-notes.html
   Strategic Lecture Notes / 25-page learning and strategy playbook.

IMPORTANT:
Keep these three files in the SAME folder. Their internal links use relative
paths, so navigation works correctly on GitHub Pages.

RECOMMENDED GITHUB STRUCTURE
----------------------------
wima-strategy/
  index.html
  operating-system.html
  lecture-notes.html

The "archive" folder contains earlier HTML versions for reference only.
Do not upload the archive to the live site unless you deliberately want
those historical versions accessible.

The "documents" folder contains supporting PowerPoint decks and the original
Deal Hub code text file.

NOTEBOOKLM
----------
Send NotebookLM the GitHub Pages URL for index.html / the repository website.
The Strategy Hub then acts as the entry point to the operating system and
lecture notes.

VERSION CONTROL
---------------
The active live files are the 3 files in /active.
Do not replace them with an older similarly named file without checking the
version first.

NEXT STEP
---------
After uploading, open the GitHub Pages URL in a normal browser and test:
Strategy Hub -> CEO Operating System -> Lecture Notes -> Strategy Hub.
Also test the Previous / Next buttons throughout the Lecture Notes.
